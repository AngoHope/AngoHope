# 안녕하세요, 김재민입니다.

미디어콘텐츠를 전공하며 영상 기획부터 촬영과 편집까지 다양한 제작 과정을 경험하고 있습니다. 작품의 주제와 감정을 영상으로 표현하고, 사람들에게 의미 있는 콘텐츠를 전달하는 데 관심이 있습니다.

## 관심 분야

- 영상 콘텐츠 기획 및 연출
- 영상 촬영과 편집
- AI 기반 영상 제작
- 미디어아트 및 디지털 콘텐츠 제작
