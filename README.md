# 안녕하세요, 김재민입니다.

미디어콘텐츠를 전공하며 기획부터 촬영과 편집까지 영상 제작의 여러 과정을 경험하고 있습니다. 영상의 주제와 분위기를 장면으로 표현하고, 완성도 있는 콘텐츠로 전달하는 데 관심이 있습니다.

## 관심 분야

- 영상 콘텐츠 기획 및 연출
- 영상 촬영과 편집
- 미디어아트 및 디지털 콘텐츠 제작

## 주요 역량 및 제작 경험

- **기획·연출:** 작품의 주제와 장면을 구상하고 스토리보드로 정리
- **촬영:** 작품의 의도와 분위기에 맞는 영상 촬영
- **편집:** 촬영한 장면을 연결해 이야기와 분위기를 구성
- **협업:** 팀 프로젝트에서 역할을 맡아 제작 과정에 참여

## 대표 프로젝트

### 나의 이름은

- **작품 소개:** 과거의 아픔을 마주하며 자신의 정체성을 찾아가는 심리 드라마·스릴러 졸업작품
- **담당 역할:** 팀장 및 감독, 스토리보드 작성, 촬영, 편집
- **결과물:** 작품 영상 및 포스터 링크는 공개 가능한 자료를 정리한 뒤 추가할 예정입니다.

### 제3회 아산 지구한바퀴 축제 영상

- **작품 소개:** 아산 지구한바퀴 축제에서 상영된 행사 관련 영상
- **담당 역할:** 영상 편집 총괄
- **결과물:** 공개 가능한 영상 링크는 추후 추가할 예정입니다.

## 제작 도구 및 장비

- **Sony FX3:** AI 영상 촬영 작업에 사용한 카메라
- 그 외 편집·디자인 소프트웨어는 실제 사용 경험을 확인해 추가할 예정입니다.

## 앞으로의 목표

영상 제작 경험을 바탕으로 기획과 연출 역량을 꾸준히 발전시키고, 사람들에게 의미와 감정을 전달하는 콘텐츠 제작자로 성장하고 싶습니다.
